# GanFan-A · 选股 Agent

> 顺势而为,只做认知内的钱。

一个基于纪律的 A 股选股 / 持仓监控工具。按一套固定交易纪律对市场打分排序,给出选股候选、盘中卖出提示、持仓监控和强制风控,带一个本地网页界面。

**数据是实时拉取的,不依赖任何预置数据文件。** 克隆下来装好依赖即可运行,运行时自动生成本地缓存和状态文件(不入库)。

---

## 交易纪律(本工具固化的逻辑)

- **只做向上趋势**:只参与处于明确上升通道的股票,不抄底、不追突破。
- **基本面硬筛**:排除亏损股;市值 100 亿以内;股价 5–30 元。
- **龙头优先**:按板块分组,组内按「涨幅 + 量能」识别龙一/龙二/龙三。
- **量能与承接**:评分重点看量比、换手、承接力度。
- **果断卖出**:急拉后 1 分钟内拉不回 → 卖;缓拉后急跌、2 次反弹失败 → 卖。
- **不补仓**:下跌/浮亏时绝不提示补仓,只在「上升趋势 + 有量承接 + 浮盈」时提示顺势加仓。
- **强制风控**:账户单日回撤达 -4.5% → 自动进入强制休息 2 天(只看不买)。

## 快速开始

```bash
# 1. 装依赖(建议用虚拟环境)
pip install -r requirements.txt

# 2. 启动网页界面
python3 app.py
# 打开 http://127.0.0.1:5001
```

首次打开会实时拉取全市场行情并算趋势(约几十秒),之后日线走本地缓存,秒级刷新。

## 功能

| 模块 | 说明 |
|---|---|
| **每日选股** | 全市场动态筛选 → 龙头识别 → 趋势/量能/承接评分 → 排序输出 Top N |
| **盘中监控** | 对自选池每只取实时分时,自动跑两条卖出规则,触发报警(界面轮询) |
| **持仓监控** | 浮盈亏 / 当日损益 / 分时卖出信号 / 趋势转坏止损 / 顺势加仓提示(下跌不补仓) |
| **复盘曲线** | 每日收盘记一条账户净值快照,界面画历史净值曲线 |
| **强制风控** | 单日回撤 -4.5% 自动触发强制休息,持仓总回撤联动 |

界面操作:登记当日回撤、增删自选池、录入/移除持仓、开启盘中与持仓轮询监控。

## 数据源

实时行情用**腾讯**(`qt.gtimg.cn` 现货 + `web.ifzq.gtimg.cn` 日线 / 分时),境内直连、抗节流。
降级链 **腾讯 → 东方财富**(akshare),两者都失败则报错,不造假数据。

> 注:部分网络环境对东方财富接口有阻断,默认首选腾讯源即可正常使用。

## 选股范围:两种模式

在 `config.yaml` 的 `runtime.full_market` 切换:

- **`full_market: true`(默认)** — 每日动态拉全市场,池子天天变,无需任何预置文件,开箱即用。
- **`full_market: false`** — 只在候选池 `universe.txt` 里选。该文件**不入库**,需自己生成:

  ```bash
  python3 build_universe.py            # 按纪律从全市场筛出候选,写入 universe.txt
  python3 build_universe.py --max-per 8 # 每个行业最多保留 8 只
  python3 build_universe.py --dry-run   # 只打印不写文件
  ```

## 配置

主要参数在 `config.yaml`:基本面筛选区间(市值/股价)、评分权重、买入/卖出阈值、风控阈值、`runtime`(top_n / hist_days / full_market / prefilter_top)等。按需调整。

## 项目结构

```
app.py                  Flask 界面 + API 端点
config.yaml             全部可调参数
build_universe.py       生成候选池 universe.txt(可选)
requirements.txt
stockagent/
  datasource.py         数据源(腾讯 / 东财),字段统一、日线缓存
  screener.py           基本面硬筛(亏损/市值/股价)
  leaders.py            板块龙头识别
  scorer.py             趋势/量能/承接评分排序
  signals.py            分时卖出规则
  positions.py          持仓分析(浮盈亏/止损/加仓/风控联动)
  risk.py               风控状态机 + 持仓/净值持久化
  pipeline.py           选股全流程串联
templates/index.html    单页界面
```

运行时生成、**不入库**的本地文件:`state.json`(风控/自选/持仓/净值)、`.cache/`(日线缓存)、`universe.txt`(候选池)。
